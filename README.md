# WarisAPP – Islamic Inheritance Calculator

WarisAPP is an Android application designed to calculate inheritance shares according to **Islamic laws of inheritance (Ilm-ul-Faraid)**.  
It helps users distribute assets fairly among heirs, following **Sunni Fiqh** or **Shia Fiqh** rules.  

---

## Features
- **Islamic Inheritance Options**
  - Choose between **Sunni** or **Shia** inheritance laws.
  - Manual entry system (future extension for NADRA integration).
  
- **Deceased Information**
  - Collects CNIC, name, gender, marital status.
  
- **Asset Entry**
  - Enter details of property, land, house, jewelry, vehicles, livestock, and gifts.
  - Calculates **total worth** of assets.
  
- **Deductions**
  - Supports deductions like:
    - Mehr (dowry)  
    - Debts  
    - Other obligations  

- **Heirs Management**
  - Add **primary heirs** (spouse, children, parents).  
  - Add **secondary heirs** (siblings, grandparents, others).  
  - Generates a **report of shares** for each heir.

- **Knowledge Section**
  - Islamic inheritance rules explained.  
  - Ahadith and references related to inheritance.

- **Complaints & Support**
  - **User Portal** – register complaints by city.  
  - **Admin Portal** – manage users, view, and resolve complaints.

---

## Tech Stack
- **Platform:** Android  
- **Languages:** Java / Kotlin (or Flutter if hybrid)  
- **Database:** Local storage (with optional server for complaints system)

---

## Example Workflow
1. Select Fiqh → *Sunni / Shia*.  
2. Enter deceased details → CNIC, gender, marital status.  
3. Add assets → property, vehicles, jewelry, etc.  
4. Add deductions → mehr, debts, etc.  
5. Add heirs → system calculates shares automatically.  
6. View a **final report** showing distribution.
